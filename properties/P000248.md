Any two disjoint cozero sets are contained in disjoint zero sets.

Equivalently, every cozero set is $C^\ast$-embedded. 

For {P6} spaces, see Theorem 14.25 of {{zb:1380.46022}} for more equivalent definitions.

We say $Z\subseteq X$ is a *zero set* if there exists a continuous function $f:X\to\mathbb{R}$ such that $Z = f^{-1}(0)$. A *cozero set* is a complement of a zero set. We say $A\subseteq X$ is $C^\ast$-embedded when every bounded continuous function $A\to\mathbb{R}$ extends to continuous function on $X$.

Note: $X$ is an F-space iff $X_{Tych}$ is an F-space, where $X_{Tych}$ is the Tychonoff reflection of $X$
(see for example {{mathse:5108293}}).

Originally introduced in Definition 2.1 of {{zb:0073.09201}}.

----
#### Meta-properties

- $X$ satisfies this property iff its Kolmogorov quotient $\text{Kol}(X)$ does.
