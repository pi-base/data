Any two disjoint cozero sets are contained in disjoint zero sets.

Equivalently, every cozero set is $C^\ast$-embedded. 

See Theorem 14.25 in {{zb:1380.46022}} for more equivalent characterizations,
of which many hold without the {P6} condition which is assumed throughout that book.

Note: $X$ is an $F$-space iff $\text{Tych}(X)$ is an $F$-space, where $\text{Tych}(X)$ is the Tychonoff reflection of $X$
(see for example {{mathse:5108293}}).

Originally introduced for {P6} spaces in Definition 2.1 of {{zb:0073.09201}}.
Here we do not assume {P6}.

---
Terminology:
A set $Z\subseteq X$ is a *zero set* if there exists a continuous function $f:X\to\mathbb{R}$ such that $Z = f^{-1}(0)$.
A *cozero set* is the complement of a zero set.
A set $A\subseteq X$ is *$C^\ast$-embedded* if every bounded continuous function $A\to\mathbb{R}$ extends to a continuous function on $X$.

----
#### Meta-properties

- $X$ satisfies this property iff its Kolmogorov quotient $\text{Kol}(X)$ does.
