If $U\subseteq X$ is a cozero set, find a cozero set $V\subseteq X$ such that $U\cup V$ is dense in $X$. Then $\overline{U}, \overline{V}$ are disjoint closed sets such that $X = \overline{U}\cup \overline{V}$, and so $\overline{U}$ is open.
