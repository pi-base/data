Since any TVS is homogeneous [(Explore)](https://topology.pi-base.org/spaces?q=TVS+%2B+not+homogeneous), it's enough to find a base of injectively path connected sets for the origin. Note that $X$ has a neighbourhood base for the origin consisting of balanced open sets (see 'insert source'), and any such set $U$ is injectively path connected: if $y_1, y_2\in U$ are colinear, take linear path from $y_1$ to $y_2$, and if $y_1, y_2$ are not colinear, take a path from $y_1$, to the origin, to $y_2$.
