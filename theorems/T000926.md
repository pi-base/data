Since any TVS is homogeneous [(Explore)](https://topology.pi-base.org/spaces?q=TVS+%2B+not+homogeneous), it's enough to a base of injectively path connected sets for the origin.

Note that $X$ has a neighbourhood basis for the origin consisting of open balanced sets: If $0\in U$ is open, then from continuity of $\mathbb{R}\times X\ni (t, x)\mapsto tx\in X$ there exists $r > 0$ and open $0\in V$ such that if $t\in (-r, r)$ and $x\in V$ then $tx\in U$. Then $W = (-r, r)V = \{tx : t\in (-r, r), x\in V\}$ is open as union of open sets $\bigcup_{t\in (-r, r)\setminus \{0\}} tV$ and balanced, that is, if $\alpha\in [-1, 1]$ and $y\in W$, then $\alpha y\in W$. Moreover $W\subseteq U$. 

If $y_1, y_2\in W, y_1\neq y_2$ and $y_1 = cy_2$ for some $c\in\mathbb{R}$, then we can assume $c\in [-1, 1]$ since otherwise we would write $y_2 = (1/c)y_1$ and switch $y_1, y_2$ with each other. Let $p(t) = (1-t)y_1+ty_2$ for $t\in [0, 1]$. Then $p$ is an injective path and $p(t) = ((1-t)c+t)y_2$ where $(1-t)c+t\in [-1, 1]$ and so $p(t)\in W$ since $W$ is balanced. Note that this covers the case when one of $y_1, y_2$ is $0$.

If $y_1, y_2\in W\setminus \{0\}, y_1\neq y_2$ and $y_1 \neq cy_2$ for all $c\in\mathbb{R}$, let $p(t) = \begin{cases} (1-2t)y_1 & t\in [0, 1/2]\\ (2t-1)y_2 & t\in [1/2, 1]\end{cases}$, then $p$ is an injective path contained in $W$.
