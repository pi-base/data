Let $S = \{x\in X : x(\lambda) = 1\text{ for finitely many }\lambda\in 2^{\mathbb{R}}\}$.
Then $|S| = |[2^{\mathbb{R}}]^{<\omega}| = |2^{\mathbb{R}}| = 2^\mathfrak{c}$ where $[A]^{<\omega}$ denotes the set of all finite subsets of $A$.
Also $|M| = \mathfrak{c}$. Thus $|F| = |S\setminus M| = 2^\mathfrak{c}$, and so $|Y| = 2^\mathfrak{c}$.
