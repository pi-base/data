$F$ is the set of $x\in X$ with finite support
(that is, $x(\lambda) = 1$ for finitely many $\lambda\in 2^\mathbb R$).
So $|F| = |[2^\mathbb R]^{<\omega}| = |2^\mathbb R| = 2^\mathfrak c$
where $[A]^{<\omega}$ denotes the set of finite subsets of $A$.
Since $|M| = \mathfrak c < |F|$, it follows that $|Y|=|M\cup F|=|F|=2^\mathfrak c$.
