For any $y \in X$, the closure $\overline{\{y\}}=\mathbb{R}\setminus B_y = (-\infty, y]$. 
So consider open $U\ni y$. 
If $U=\mathbb{R}$ then $U\cap \overline{\{y\}} = (-\infty, y]\neq \{y\}$. 
If $U=(a,\infty)$ with $a < y$, then $U \cap \overline{\{y\}} = (a,y]\neq \{y\}$ either. 
So the space cannot be {P247}.
