If $n\in\omega$, then $\{n\} = [0, n+1)\setminus [0, n) = \omega_1\setminus (\omega_1\setminus \{n\})$ is clopen, and so a cozero set. It follows that any $A\subseteq \omega$ is a cozero set as countable union of cozero sets. If $A\subseteq\omega$ is infinite, then $\overline{A} = A\cup [\omega, \omega_1)$, and so closures of any two disjoint cozero sets $A, B\subseteq\omega$ intersect.
