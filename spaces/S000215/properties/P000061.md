Note that if $V\subseteq X\setminus (\mathbb{R}\times \{0\})$ then $V = \bigcup_n V_n$ where $V_n = V\setminus(\mathbb{R}\times (-\frac{1}{n}, \frac{1}{n}))$ and each $V_n$ is clopen, so that $V$ is a cozero set as a countable union of cozero sets.

If now $U\subseteq X$, let $V = X\setminus (U\cup (\mathbb{R}\times \{0\}))$.
Then $V$ is a cozero set disjoint from $U$ and $U\cup V$ contains $X\setminus (\mathbb{R}\times \{0\})$ which is dense in $X$, so that $U\cup V$ is dense in $X$.
