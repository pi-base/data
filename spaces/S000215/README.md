Let $X=\mathbb R^2$ with each point $(x,y)$ with $y\ne 0$ isolated
and each point $(x,0)$ having as local base the collection of open sets $U_n(x)$ ($n=1,2,\dots$),
where $U_n(x)$ is the union of the three line segments
* $\{(x, y): -1/n < y < 1/n\}$,
* $\{(x+1+y, y): 0 < y < 1/n\}$,
* $\{(x+\sqrt{2}+y, -y) : 0 < y < 1/n\}$.

Introduced by Mysior in {{zb:0469.54011}}.
Also described in Example 5 of {{zb:1265.54111}}.
